**Lectura de los estados.** «Aprobado — ejecución informada» significa que el método estaba en la rama del PR para la que el equipo informó una suite completa satisfactoria; no necesariamente se conservó el resultado individual del método. «Aprobado — verificación posterior» significa que el test se aprobó individualmente en GitHub Actions después del cierre del Sprint 1. «Aprobado — prueba manual informada» significa que el equipo describió una comprobación manual satisfactoria, sin que eso equivalga a un resultado automatizado. «Sin evidencia de ejecución» significa que no se localizó un registro del resultado; no implica que la funcionalidad haya fallado.
