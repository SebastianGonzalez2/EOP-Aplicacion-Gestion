# ¿Qué hay acá?

Esta guía sirve para entender cómo funciona el inicio de sesión de EOP con Microsoft Entra ID y repasar cómo se podría repetir en otro proyecto.

- `capitulos/`: explicaciones paso a paso en Markdown.
- `imagenes/`: capturas de la aplicación y espacio para las del portal.
- `herramientas/`: scripts para juntar los capítulos y generar el PDF.
- `guia.json`: indica el orden de los capítulos y otros datos de la guía.
- `salida/`: el PDF listo para leer.

Si querés leerla, abrí [el PDF](salida/Guia-Autenticacion-Entra-ID.pdf). Si querés editarla o regenerarla, seguí las instrucciones del [README técnico](README.md).

No es código necesario para ejecutar EOP; es material de capacitación. Nunca guardes secretos ni credenciales en las capturas o documentos.
