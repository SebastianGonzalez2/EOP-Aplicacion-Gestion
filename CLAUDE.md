# Sistema de Gestión EOP

Las reglas de este proyecto están en **[`AGENTS.md`](./AGENTS.md)**, en la raíz del repositorio.

**Leé ese archivo antes de escribir código.** Contiene el stack, la arquitectura, los requerimientos no funcionales que todo código debe cumplir, las reglas de negocio transversales y las convenciones de ramas y commits.

Se mantiene en un solo archivo porque el equipo trabaja con dos asistentes distintos —Claude Code y Codex— y Codex lee `AGENTS.md` de forma automática. Tener dos copias llevaría a que se desincronicen.

Cualquier cambio en las reglas del proyecto va en `AGENTS.md`, no acá.
